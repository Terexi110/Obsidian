# Задача 19: Числа с разностью, не делящейся на n

> [!question] Условие
> Какое наибольшее количество натуральных чисел можно взять, чтобы разность никаких двух из них не делилась на $n$?

---

### Решение

1. **Критерий делимости разности:**
   Разность двух чисел $a - b$ делится на $n$ тогда и только тогда, когда $a$ и $b$ дают **одинаковый остаток** при делении на $n$ ($a \equiv b \pmod n$).
   Следовательно, условие задачи требует, чтобы **все выбранные числа имели попарно различные остатки при делении на $n$**.

2. **Оценка (принцип Дирихле):**
   При делении на натуральное число $n$ возможны ровно $n$ различных остатков:
   $$0, 1, 2, \dots, n - 1$$
   Если взять $n + 1$ или более чисел («кроликов») и распределить их по $n$ остаткам («клеткам»), то по принципу Дирихле найдутся хотя бы два числа с одинаковым остатком. Их разность будет делиться на $n$.
   Значит, взять больше $n$ чисел невозможно.

3. **Пример для $n$ чисел:**
   Возьмём первые $n$ натуральных чисел:
   $$\{1, 2, 3, \dots, n\}$$
   Их остатки при делении на $n$ равны $\{1, 2, \dots, n-1, 0\}$. Все остатки различны, поэтому разность никаких двух чисел на $n$ не делится.

---

> [!success] Ответ
> **$n$**
