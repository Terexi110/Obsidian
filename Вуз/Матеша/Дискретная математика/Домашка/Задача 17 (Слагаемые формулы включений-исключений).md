# Задача 17: Количество слагаемых в формуле включений-исключений

> [!question] Условие
> Докажите, что в формуле включений-исключений для $n$ множеств ровно $2^n - 1$ слагаемых.

---

### Формулировка формулы включений-исключений
Для $n$ конечных множеств $A_1, A_2, \dots, A_n$:
$$|A_1 \cup \dots \cup A_n| = \sum_{i} |A_i| - \sum_{i < j} |A_i \cap A_j| + \sum_{i < j < k} |A_i \cap A_j \cap A_k| - \dots + (-1)^{n-1} |A_1 \cap \dots \cap A_n|$$

В компактной записи через непустые подмножества индексов $I \subseteq \{1, 2, \dots, n\}$:
$$\left| \bigcup_{i=1}^n A_i \right| = \sum_{\emptyset \neq I \subseteq \{1, \dots, n\}} (-1)^{|I| - 1} \left| \bigcap_{i \in I} A_i \right|$$

---

### Доказательство

#### Способ 1 (комбинаторный, через независимый выбор)
Каждое слагаемое в формуле представляет собой пересечение некоторого набора множеств.
Чтобы составить слагаемое, мы подходим к каждому множеству $A_1, A_2, \dots, A_n$ и решаем: включать его в пересечение или нет?
* Для каждого из $n$ множеств есть ровно **2 варианта** (включить / не включить).
* Всего существует $2 \times 2 \times \dots \times 2 = 2^n$ различных комбинаций выбора.
* Слагаемое должно содержать хотя бы одно множество, поэтому вариант «не выбрать ни одного множества» исключается (ровно 1 случай).

Итого слагаемых:
$$2^n - 1$$

#### Способ 2 (через бином Ньютона)
Посчитаем слагаемые по количеству пересекаемых множеств:
* По 1 множеству: $\binom{n}{1}$ слагаемых;
* По 2 множества: $\binom{n}{2}$ слагаемых;
* ...
* Пересечение всех $n$ множеств: $\binom{n}{n}$ слагаемых.

Сумма всех слагаемых:
$$\sum_{k=1}^n \binom{n}{k} = \sum_{k=0}^n \binom{n}{k} - \binom{n}{0} = (1 + 1)^n - 1 = 2^n - 1$$

---

> [!success] Вывод
> Количество слагаемых строго равно **$2^n - 1$**, что и требовалось доказать.
