## 1. Сводная таблица комбинаторных моделей

| Задача / Условие | Комбинаторная модель | Формула | Пояснение |
| :--- | :--- | :--- | :--- |
| **Выбор $k$ из $n$ без учёта порядка** | Сочетания без повторений | $\dbinom{n}{k} = \dfrac{n!}{k!(n-k)!}$ | Выбор подмножества размера $k$ |
| **Выбор $k$ из $n$ с учётом порядка** | Размещения без повторений | $A_n^k = \dfrac{n!}{(n-k)!}$ | Упорядоченный список без повторений |
| **Упорядочивание $n$ различных элементов** | Перестановки | $P_n = n!$ | Число взаимно-однозначных отображений |
| **Перестановки $n$ элементов, где $k$ фиксированы по возрастанию** | Симметрия порядков | $\dfrac{n!}{k!} = A_n^{n-k}$ | Из $k!$ порядков подходит ровно один |
| **Выбор $k$ предметов из ряда $n$ без соседей** | Белые и чёрные шары / сдвиг номеров | $\dbinom{n - k + 1}{k}$ | Распределение $k$ чёрных шаров по $(n-k+1)$ карманам |
| **Выбор $k$ из ряда $n$ с зазором не менее $d$** | Склейка блоков $[\bullet \underbrace{\circ \dots \circ}_{d-1}]$ | $\dbinom{n - (k-1)(d-1)}{k}$ | Номера $a_{i+1} - a_i \ge d$ |
| **Выбор $k$ из $n$ по кругу без соседей** | Теорема Капланского | $\dfrac{n}{n - k}\dbinom{n - k}{k}$ | Исключение соседства на концах цикла |
| **Раскладка $n$ шаров по $k$ ящикам ($x_i \ge 1$)** | Шары и перегородки (натуральные) | $\dbinom{n - 1}{k - 1}$ | Выбор $k-1$ мест из $n-1$ промежутка |
| **Раскладка $n$ шаров по $k$ ящикам ($x_i \ge 0$)** | Сочетания с повторениями $\bar{C}_k^n$ | $\dbinom{n + k - 1}{k - 1} = \dbinom{n + k - 1}{n}$ | Выбор мест под $k-1$ перегородок в ряду |
| **Раскладка с ограничениями $x_i \ge c_i$** | Сдвиг $y_i = x_i - c_i \ge 0$ | $\dbinom{n - \sum c_i + k - 1}{k - 1}$ | Вычитание минимально гарантированного запаса |
| **Неравенство $x_1 + \dots + x_k \le n$ ($x_i \ge 0$)** | Фиктивная переменная $x_{k+1}$ | $\dbinom{n + k}{k}$ | Уравнение на $k+1$ переменную с суммой $n$ |

## 2. Отображения конечных множеств ($|X| = m$, $|Y| = n$)

Пусть $f: X \to Y$, где $|X| = m$ (прообразы), $|Y| = n$ (образы).

```
        X (мощность m)              Y (мощность n)
       ┌──────────────┐            ┌──────────────┐
       │      x1──────┼───────────>│ y1           │
       │      x2──────┼─────┐      │              │
       │      x3──────┼─────┴─────>│ y2           │
       └──────────────┘            │ y3 (свободен)│
                                   └──────────────┘
```

### Критерии типов отображений
* **Инъекция («один к одному»):** $f(x_1) = f(x_2) \implies x_1 = x_2$.
  * В каждый $y \in Y$ входит **не более одной** стрелки: $|f^{-1}(y)| \le 1$.
  * Необходимое условие: **$m \le n$** (при $m > n$ инъекций нет по принципу Дирихле).
  * Количество инъекций:
    $$N_{\text{ин}} = A_n^m = \frac{n!}{(n - m)!} = n(n-1)\dots(n-m+1)$$
* **Сюръекция («на всё множество»):** $\forall y \in Y \; \exists x \in X: f(x) = y$.
  * В каждый $y \in Y$ входит **не менее одной** стрелки: $|f^{-1}(y)| \ge 1$.
  * Необходимое условие: **$m \ge n$** (при $m < n$ сюръекций нет).
  * Количество сюръекций:
    $$N_{\text{сюр}} = n! \cdot S(m, n) = \sum_{j=0}^n (-1)^{n-j} \binom{n}{j} j^m$$
* **Биекция (взаимно однозначно):** одновременно инъекция и сюръекция.
  * В каждый $y \in Y$ входит **ровно одна** стрелка: $|f^{-1}(y)| = 1$.
  * Необходимое условие: **$m = n$**.
  * Количество биекций: $N_{\text{би}} = n!$.
* **Всего отображений:** $N = n^m$ ($m$ независимых выборов из $n$ вариантов).

> [!tip] Паттерн из ДЗ (№15): Инъекции vs Сюръекции
> При $m \gg n$ сюръекций $m \to n$ **несравнимо больше**, чем инъекций $n \to m$:
> * Инъекций $5 \to 20$: $A_{20}^5 \approx 1{,}86 \cdot 10^6$.
> * Сюръекций $20 \to 5$: $5! \cdot S(20, 5) > 5! \cdot 5^{15} > 10^{12}$ (разница в миллионы раз).

## 3. Числа Стирлинга второго рода $S(n, k)$

> [!abstract] Определение
> **$S(n, k)$** — количество способов разбить множество из $n$ различимых элементов на $k$ непустых неразличимых подмножеств (блоков).

### Базовые формулы и свойства
1. **Рекуррентное соотношение:**
   $$S(n, k) = S(n - 1, k - 1) + k \cdot S(n - 1, k)$$
   *(Логика: последний элемент образует отдельный блок — $S(n-1, k-1)$, либо добавляется в один из $k$ существующих блоков — $k \cdot S(n-1, k)$).*
2. **Краевые и частные значения:**
   * $S(n, 1) = 1$ (все элементы в одном блоке)
   * $S(n, n) = 1$ (каждый элемент в своём блоке)
   * $S(n, n - 1) = \dbinom{n}{2}$ (ровно одна пара склеилась, остальные одиночные; например, $S(4, 3) = \binom{4}{2} = 6$)
   * $S(n, 2) = 2^{n-1} - 1$ (фиксация 1-го элемента: у остальных $n-1$ элементов есть 2 выбора, минус случай, когда 2-й блок пуст)
3. **Связь с сюръекциями:**
   $$N_{\text{сюр}}(X \to Y) = |Y|! \cdot S(|X|, |Y|)$$

## 4. Принцип включений-исключений (ПВИ)

### Формулы
* Для двух множеств: $|A \cup B| = |A| + |B| - |A \cap B|$.
* Для трёх множеств:
  $$|A \cup B \cup C| = \sum |A| - \sum |A \cap B| + |A \cap B \cap C|$$
* В общем виде для $n$ множеств:
  $$\left| \bigcup_{i=1}^n A_i \right| = \sum_{\emptyset \neq I \subseteq \{1, \dots, n\}} (-1)^{|I| - 1} \left| \bigcap_{i \in I} A_i \right|$$

### Ключевые факты и приёмы
* **Число слагаемых (№17):** в формуле для $n$ множеств ровно **$2^n - 1$** слагаемых (выбор непустого подмножества множеств $\sum_{k=1}^n \binom{n}{k} = 2^n - 1$).
* **ПВИ для площадей и вероятностей (№18):**
  $$S(A_1 \cap A_2) + S(A_2 \cap A_3) + S(A_3 \cap A_1) = \sum S(A_i) + S(A_1 \cap A_2 \cap A_3) - S(A_1 \cup A_2 \cup A_3)$$
  Если $\sum S(A_i) \ge \frac{3}{2}$, $S(\cup) \le 1$, $S(\cap \cap) \ge 0$, то сумма трёх пересечений $\ge \frac{1}{2}$.

## 5. Принцип Дирихле (Pigeonhole Principle)

1. **Дискретный (обобщённый):** если $N$ предметов разложить по $k$ ящикам, то хотя бы в одном ящике будет не менее:
   $$\left\lceil \frac{N}{k} \right\rceil \text{ предметов.}$$
2. **Непрерывный (метод усреднения):** если среднее арифметическое набора величин равно $\mu$, то максимальная величина не меньше среднего:
   $$\max(x_1, \dots, x_m) \ge \frac{x_1 + \dots + x_m}{m}$$
   *(В задаче 18: сумма площадей трёх попарных пересечений $\ge \frac{1}{2} \implies$ среднее $\ge \frac{1}{6} \implies$ найдётся пересечение $\ge \frac{1}{6}$).*
3. **Метод деления на категории (№21):** если события происходят независимо в двух фазах (например, выбор стола 1 или 2 утром и в обед), образуется $2 \times 2 = 4$ комбинированные категории. Для 9 человек: $\lceil 9/4 \rceil = 3$. Чтобы доказать невозможность 4, строится контрпример с распределением $3, 2, 2, 2$.
4. **По остаткам (№19):** разность $a - b$ делится на $n \iff a \equiv b \pmod n$. При делении на $n$ существует $n$ различных остатков. Значит, максимум чисел без одинаковых остатков равен $n$.
5. **Геометрический принцип (№20):** фигура диаметра $d$ не может содержать две точки, расстояние между которыми строго больше $d$. Равносторонний треугольник со стороной $a$ имеет вершины на расстоянии $a$, поэтому меньший треугольник ($d < a$) содержит $\le 1$ вершины. Три вершины невозможно покрыть двумя меньшими треугольниками ($\lceil 3/2 \rceil = 2$).

## 6. Бином Ньютона и полиномиальная теорема

### Базовые разложения
1. **Бином Ньютона:**
   $$(a + b)^n = \sum_{k=0}^n \binom{n}{k} a^{n-k} b^k$$
2. **Полиномиальная теорема:**
   $$(a_1 + a_2 + \dots + a_m)^N = \sum_{k_1 + \dots + k_m = N} \frac{N!}{k_1! \, k_2! \dots k_m!} a_1^{k_1} a_2^{k_2} \dots a_m^{k_m}$$

### Типовые задачи и алгоритмы

#### А. Поиск наибольшего слагаемого в биноме $(a + b)^n$
1. Записать общий член $a_k = \binom{n}{k} a^{n-k} b^k$.
2. Составить отношение соседних членов: $\dfrac{a_{k+1}}{a_k}$.
3. Решить неравенство $\dfrac{a_{k+1}}{a_k} \ge 1$.
   * Для $(1 + 3)^n$: отношение $\frac{3(n-k)}{k+1} \ge 1 \iff k \le \frac{3n-1}{4}$.
   * Наибольший номер: $k_{\max} = \lfloor \frac{3n+3}{4} \rfloor$ (при $3n \equiv 1 \pmod 4$ наибольшими являются два соседних слагаемых).

#### Б. Поиск коэффициента при мономе в $(a_1 + \dots + a_m)^N$
1. Записать общий член: $\dfrac{N!}{k_1! \dots k_m!} \cdot \prod a_i^{k_i}$.
2. Приравнять показатели при каждой переменной к заданным степеням.
3. **Критическая проверка:** проверить сумму показателей $\sum_{i=1}^m k_i = N$. Если сумма не равна $N$ — коэффициент **строго равен 0**.
4. **Приём факторизации:** если многочлен раскладывается на множители, раскрывать произведение независимых биномов:
   $$(1 + x + x^2 + x^3)^n = (1 + x)^n (1 + x^2)^n = \left(\sum_i \binom{n}{i} x^i\right) \left(\sum_j \binom{n}{j} x^{2j}\right)$$
   Затем искать коэффициент через условие $i + 2j = \text{нужная степень}$.

#### В. Вычисление взвешенных сумм с биномиальными коэффициентами
Базовая производящая функция: $f(x) = (1 + x)^n = \sum_{k=0}^n \binom{n}{k} x^k$.

| Множитель при $\binom{n}{k}$ | Операция над $f(x)$ | Значение суммы при $x = 1$ |
| :--- | :--- | :--- |
| $1$ | Подстановка $x = 1$ | $\sum \binom{n}{k} = 2^n$ |
| $k$ | Первая производная $f'(1)$ | $\sum k \binom{n}{k} = n 2^{n-1}$ |
| $k(k - 1)$ | Вторая производная $f''(1)$ | $\sum k(k-1)\binom{n}{k} = n(n-1) 2^{n-2}$ |
| $k^2$ | $f''(1) + f'(1)$ или $[x f'(x)]'_{x=1}$ | $\sum k^2 \binom{n}{k} = n(n+1) 2^{n-2}$ |
| $\dfrac{1}{k + 1}$ | Интегрирование $\int_0^1 (1+x)^n dx$ | $\sum \dfrac{\binom{n}{k}}{k+1} = \dfrac{2^{n+1} - 1}{n + 1}$ |
| $\sum_{k=0}^n C_n^k (k^2 + 2k - \frac{1}{k+1})$ | Комбинация вышеуказанных | $n(n + 5) 2^{n-2} - \dfrac{2^{n+1} - 1}{n + 1}$ |

## 7. Рекуррентные соотношения и разложения чисел (композиции)

> [!abstract] Определение
> **Разложение (состав / composition) числа $n$** — представление $n$ в виде суммы натуральных слагаемых с учётом порядка: $x_1 + x_2 + \dots + x_k = n$.

Числа Фибоначчи: $F_1 = 1, \; F_2 = 1, \; F_3 = 2, \; F_4 = 3, \; F_5 = 5, \; \dots, \; F_n = F_{n-1} + F_{n-2}$.

| Тип разложения числа $n$ | Рекуррентность | Начальные члены | Выражение через $F$ |
| :--- | :--- | :--- | :--- |
| **На части, равные $1$ или $2$** | $B_n = B_{n-1} + B_{n-2}$ | $B_1 = 1, B_2 = 2$ | $B_n = F_{n+1}$ |
| **На нечётные слагаемые ($1, 3, 5, \dots$)** | $C_n = C_{n-1} + C_{n-2}$ | $C_1 = 1, C_2 = 1$ | $C_n = F_n$ |
| **На слагаемые, большие $1$ ($x_i \ge 2$)** | $A_n = A_{n-1} + A_{n-2}$ | $A_1 = 0, A_2 = 1, A_3 = 1$ | $A_n = F_{n-1}$ (при $n \ge 2$) |

> [!tip] Универсальный метод вывода рекуррентности
> Смотрим на **последнее слагаемое $x$**:
> 1. Если $x$ принимает минимально возможное значение $x_0$, оставшаяся сумма равна $n - x_0 \implies$ даёт ветку $T_{n - x_0}$.
> 2. Если $x > x_0$, вычитаем из него шаг допустимости $d$: новое слагаемое $x' = x - d$ остаётся допустимым, а общая сумма уменьшается на $d \implies$ даёт ветку $T_{n - d}$.
> 3. Итог: $T_n = T_{n - x_0} + T_{n - d}$.

## 8. Экспресс-чеклист перед сдачей работы

1. [ ] **Порядок важен или нет?** Если важен — размещения $A_n^k$ или перестановки $P_n$; если нет — сочетания $C_n^k$.
2. [ ] **Есть ли запрет на соседство в ряду?** Используй кодирование белыми/чёрными шарами $\binom{n-k+1}{k}$ или сдвиг $b_i = a_i - (i-1)$.
3. [ ] **Раскладка предметов по группам:** различимы ли предметы и ящики?
   * Одинаковые предметы в различимые ящики $\implies$ **шары и перегородки** ($\binom{n-1}{k-1}$ для непустых, $\binom{n+k-1}{k-1}$ для неотрицательных).
   * Различные предметы в неразличимые непустые группы $\implies$ **числа Стирлинга** $S(n, k)$.
   * Различные предметы в различные непустые ящики $\implies$ **сюръекции** $k! \cdot S(n, k)$.
4. [ ] **В полиномиальной теореме:** сумма степеней $\sum k_i$ ОБЯЗАНА быть равна $N$. Если не равна — пиши ответ $0$.
5. [ ] **В формуле включений-исключений:** ровно $2^n - 1$ слагаемых, знаки чередуются ($+ - + - \dots$).
6. [ ] **В принципе Дирихле:** чётко назови, что является «кроликами» ($N$), а что «клетками» ($k$), и возьми потолок $\lceil N/k \rceil$.
