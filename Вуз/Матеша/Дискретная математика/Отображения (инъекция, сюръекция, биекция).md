# Отображения: Инъективность, Сюръективность, Биективность

Теоретический конспект по дискретной математике и теории множеств.

---

## 1. Базовые понятия и терминология

Пусть $X$ и $Y$ — произвольные множества. 

> [!abstract] Определение: Отображение (функция)
> **Отображением** (или функцией) $f$ из множества $X$ в множество $Y$ (обозначается $f: X \to Y$) называется правило или закон, по которому **каждому** элементу $x \in X$ сопоставляется **единственный** элемент $y \in Y$. При этом пишут $y = f(x)$.

* $X$ называется **областью определения** (domain): $\mathrm{dom}(f) = X$.
* $Y$ называется **областью прибытия** / **кодоменом** (codomain): $\mathrm{codom}(f) = Y$.
* Множество $\mathrm{im}(f) = f(X) = \{f(x) \mid x \in X\} \subseteq Y$ называется **образом** (image, range) отображения $f$.
* Для элемента $y \in Y$ множество $f^{-1}(y) = \{x \in X \mid f(x) = y\}$ называется **полным прообразом** элемента $y$.

---

## 2. Инъективность (Инъекция, «Один к одному» / One-to-One)

> [!info] Интуитивный смысл
> Отображение переводит **разные** элементы в **разные**. Стрелки из множества $X$ в множество $Y$ нигде не «слипаются».

### Формальные определения
Отображение $f: X \to Y$ называется **инъективным** (или **инъекцией**), если:
$$\forall x_1, x_2 \in X: \quad x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$$

Эквивалентная формулировка (через контрапозицию, чаще всего используется в доказательствах):
$$\forall x_1, x_2 \in X: \quad f(x_1) = f(x_2) \implies x_1 = x_2$$

На языке прообразов: для любого $y \in Y$ его прообраз $f^{-1}(y)$ содержит **не более одного** элемента ($|f^{-1}(y)| \le 1$).

### Графическая иллюстрация
```text
  X          Y
( 1 ) ----> ( a )
( 2 ) ----> ( b )
( 3 ) ----> ( c )
            ( d )   <-- элемент может остаться без прообраза, это допустимо
```

### Свойства для конечных множеств
* Если $f: X \to Y$ — инъекция, то $|X| \le |Y|$.
* Если $|X| > |Y|$, то инъекции не существует (принцип Дирихле / Pigeonhole Principle).

### Примеры
* **Инъекция:** $f: \mathbb{R} \to \mathbb{R}, \; f(x) = 2x + 3$.
  * *Доказательство:* Пусть $f(x_1) = f(x_2) \iff 2x_1 + 3 = 2x_2 + 3 \iff 2x_1 = 2x_2 \iff x_1 = x_2$.
* **НЕ инъекция:** $f: \mathbb{R} \to \mathbb{R}, \; f(x) = x^2$.
  * *Контрпример:* $f(-2) = f(2) = 4$, но $-2 \neq 2$.
* **Инъекция (при сужении области):** $f: [0, +\infty) \to \mathbb{R}, \; f(x) = x^2$ — инъективно, так как отрицательных чисел нет.

## 3. Сюръективность (Сюръекция, «На» / Onto)

> [!info] Интуитивный смысл
> Отображение **полностью покрывает** всё целевое множество $Y$. В множестве $Y$ нет элементов, в которые не пришла хотя бы одна стрелка.

### Формальные определения
Отображение $f: X \to Y$ называется **сюръективным** (или **сюръекцией**), если:
$$\forall y \in Y \quad \exists x \in X: \quad f(x) = y$$

На языке образов:
$$\mathrm{im}(f) = f(X) = Y$$

На языке прообразов: для любого $y \in Y$ его прообраз $f^{-1}(y)$ содержит **хотя бы один** элемент ($|f^{-1}(y)| \ge 1$).

### Графическая иллюстрация
```text
  X          Y
( 1 ) ----> ( a )
( 2 ) ---\ 
          ->( b )   <-- в один элемент может приходить несколько стрелок
( 3 ) ---/
```

### Свойства для конечных множеств
* Если $f: X \to Y$ — сюръекция, то $|X| \ge |Y|$.
* Если $|X| < |Y|$, то сюръекции не существует.

### Примеры
* **Сюръекция:** $f: \mathbb{R} \to \mathbb{R}, \; f(x) = x^3$.
  * *Доказательство:* Возьмем любое $y \in \mathbb{R}$. Всегда существует $x = \sqrt[3]{y} \in \mathbb{R}$ такое, что $f(x) = (\sqrt[3]{y})^3 = y$.
* **НЕ сюръекция:** $f: \mathbb{R} \to \mathbb{R}, \; f(x) = x^2$.
  * *Контрпример:* Возьмем $y = -1 \in Y$. Уравнение $x^2 = -1$ не имеет решений в $\mathbb{R}$.
* **Сюръекция (при изменении кодомена):** $f: \mathbb{R} \to [0, +\infty), \; f(x) = x^2$ — сюръективно, так как для любого $y \ge 0$ существует $x = \sqrt{y}$.

> [!warning] Важное замечание
> Сюръективность всегда зависит от указанного множества прибытия $Y$ (кодомена)! Одно и то же аналитическое выражение может быть сюръекцией или не быть ей в зависимости от того, как определен $Y$.

## 4. Биективность (Биекция, Взаимно-однозначное соответствие)

> [!info] Интуитивный смысл
> Идеальное спаривание: каждому элементу из $X$ соответствует ровно один элемент из $Y$, и каждый элемент из $Y$ спарен с ровно одним элементом из $X$.

### Формальные определения
Отображение $f: X \to Y$ называется **биективным** (или **биекцией**), если оно **одновременно инъективно и сюръективно**:
$$\forall y \in Y \quad \exists! x \in X: \quad f(x) = y$$
(символ $\exists!$ означает «существует единственный»).

На языке прообразов: для любого $y \in Y$ мощность прообраза в точности равна единице:
$$|f^{-1}(y)| = 1 \quad \forall y \in Y$$

### Графическая иллюстрация
```text
  X          Y
( 1 ) ----> ( a )
( 2 ) ----> ( b )
( 3 ) ----> ( c )
```

### Обратимость (критерий биективности)
Отображение $f: X \to Y$ биективно тогда и только тогда, когда существует **обратное отображение** $f^{-1}: Y \to X$ такое, что:
$$f^{-1} \circ f = \mathrm{id}_X \quad \text{и} \quad f \circ f^{-1} = \mathrm{id}_Y$$
где $\mathrm{id}_X(x) = x$ и $\mathrm{id}_Y(y) = y$ — тождественные отображения.

### Свойства для конечных множеств
* Если $f: X \to Y$ — биекция, то $|X| = |Y|$.
* Для конечных множеств одинаковой мощности ($|X| = |Y| < \infty$) следующие условия равносильны:
  1. $f$ — инъективно;
  2. $f$ — сюръективно;
  3. $f$ — биективно.
*(Внимание: для бесконечных множеств это не так! Например, $f: \mathbb{N} \to \mathbb{N}, f(n) = n + 1$ инъективно, но не сюръективно).*

## 6. Алгебра композиций

Пусть заданы отображения $f: X \to Y$ и $g: Y \to Z$. Их композиция $(g \circ f): X \to Z$ определяется как $(g \circ f)(x) = g(f(x))$.

> [!tip] Свойства композиции:
> 1. Если $f$ и $g$ инъективны $\implies (g \circ f)$ **инъективна**.
> 2. Если $f$ и $g$ сюръективны $\implies (g \circ f)$ **сюръективна**.
> 3. Если $f$ и $g$ биективны $\implies (g \circ f)$ **биективна**, причем $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$.
> 
> **Обратные следствия:**
> * Если $(g \circ f)$ инъективна $\implies f$ **инъективна** (про $g$ утверждать ничего нельзя).
> * Если $(g \circ f)$ сюръективна $\implies g$ **сюръективна** (про $f$ утверждать ничего нельзя).

## 7. Комбинаторика отображений

Пусть $|X| = m$, $|Y| = n$ — конечные множества.

1. **Всего различных отображений из $X$ в $Y$:**
   $$N = n^m$$
   *(Каждый из $m$ элементов множества $X$ имеет $n$ независимых вариантов выбора образа).*

2. **Количество инъекций из $X$ в $Y$:**
   $$N_{\text{ин}} = \begin{cases} A_n^m = \dfrac{n!}{(n - m)!} = n(n-1)\dots(n-m+1), & \text{если } m \le n \\ 0, & \text{если } m > n \end{cases}$$

3. **Количество биекций из $X$ в $Y$:**
   $$N_{\text{би}} = \begin{cases} n!, & \text{если } m = n \\ 0, & \text{если } m \neq n \end{cases}$$
   *(Биекция конечного множества на себя называется перестановкой).*

4. **Количество сюръекций из $X$ в $Y$:**
   $$N_{\text{сюр}} = n! \cdot S(m, n) = \sum_{k=0}^{n} (-1)^{n-k} \binom{n}{k} k^m$$
   *(где $S(m, n)$ — числа Стирлинга второго рода, количество способов разбить $m$-элементное множество на $n$ непустых блоков).*

## 8. Алгоритм исследования отображения на практике

Чтобы исследовать отображение $f: X \to Y$:

1. **Проверка на инъективность:**
   * Записать уравнение $f(x_1) = f(x_2)$.
   * Алгебраически упростить его.
   * Если удается строго доказать, что $x_1 = x_2$ — отображение **инъективно**.
   * Если находятся конкретные $x_1 \neq x_2$ из $X$, дающие $f(x_1) = f(x_2)$ — отображение **не инъективно**.

2. **Проверка на сюръективность:**
   * Записать уравнение $f(x) = y$, считая $y \in Y$ фиксированным параметром.
   * Выразить $x$ через $y$.
   * Проверить: для **любого** ли $y \in Y$ найденное значение $x$ существует и принадлежит области определения $X$?
   * Если да — отображение **сюръективно**.
   * Если существует хотя бы один $y \in Y$, для которого подходящего $x \in X$ нет — отображение **не сюръективно**.

3. **Проверка на биективность:**
   * Если выполнены оба пункта (1) и (2) $\implies$ отображение **биективно**.
   * Формула $x = \dots$ из шага сюръективности задает обратную функцию $f^{-1}(y)$.
