# Метод шаров и перегородок и кодирование шарами

Полное руководство и шпаргалка по методам **«Шаров и перегородок» (Stars and Bars)** и **«Белых и чёрных шаров»** для решения комбинаторных задач.

---

## 1. Когда какой метод применять?

| Метод | Что дано в задаче | Типичная формулировка |
| :--- | :--- | :--- |
| **Шары и перегородки** | Раскладка $n$ одинаковых предметов по $k$ различимым ящикам | *«Сколько решений имеет уравнение $x_1 + \dots + x_k = n$?»*, *«Сколькими способами раздать $n$ одинаковых конфет $k$ детям?»* |
| **Белые и чёрные шары** | Выбор $k$ предметов из ряда из $n$ предметов с запретом на соседство | *«Выбрать $k$ книг из $n$ на полке так, чтобы никакие две не стояли рядом»*, *«Сколько подмножеств без соседних элементов?»* |

---

## ЧАСТЬ I. Классический метод шаров и перегородок (Stars & Bars)

Задача: найти число решений уравнения:
$$x_1 + x_2 + \dots + x_k = n$$
где $n$ — количество одинаковых предметов (шаров $\circ$), а $k$ — количество различных групп (ящиков). Чтобы разбить ряд шаров на $k$ групп, нужно поставить **$k - 1$ перегородку** ($|$).

```text
Группа 1       Группа 2          Группа k
  ooo     |       oo       | ... |   oooo
 (x1=3)         (x2=2)              (xk=4)
```

---

### Случай 1. В каждом ящике хотя бы по одному предмету ($x_i \ge 1$, натуральные числа)

* **Модель:** выкладываем $n$ шаров в ряд. Между ними есть ровно **$n - 1$ промежуток**.
* В каждый промежуток можно поставить **не более одной** перегородки (иначе между ними будет пусто, т.е. $x_i = 0$).
* Нужно выбрать $k - 1$ промежуток из $n - 1$ возможных.

> [!important] Формула (для $x_i \ge 1$):
> $$N = \binom{n - 1}{k - 1}$$

---

### Случай 2. Ящики могут быть пустыми ($x_i \ge 0$, целые неотрицательные числа)

* **Модель:** теперь перегородки могут стоять рядом друг с другом или по краям ряда.
* Всего в ряду оказывается $n$ шаров и $k - 1$ перегородок $\implies$ суммарно **$n + k - 1$ позиций**.
* Любое решение однозначно задаётся выбором мест для $k - 1$ перегородок (или для $n$ шаров).

> [!important] Формула (для $x_i \ge 0$, число сочетаний с повторениями $\bar{C}_k^n$):
> $$N = \binom{n + k - 1}{k - 1} = \binom{n + k - 1}{n}$$

---

### Случай 3. Произвольные нижние ограничения ($x_i \ge c_i$)

Если на каждую переменную наложено ограничение вида $x_i \ge c_i$:
1. Сделаем замену переменных:
   $$y_i = x_i - c_i \ge 0$$
2. Подставим в уравнение:
   $$(y_1 + c_1) + (y_2 + c_2) + \dots + (y_k + c_k) = n$$
   $$y_1 + y_2 + \dots + y_k = n - \sum_{i=1}^k c_i$$
3. Получили классический Случай 2 с новой суммой $n' = n - \sum c_i$.

> [!tip] Пример
> Найти число решений $x_1 + x_2 + x_3 = 15$ при $x_1 \ge 2, x_2 \ge 3, x_3 \ge 1$.
> Замена: $y_1 = x_1 - 2 \ge 0, \; y_2 = x_2 - 3 \ge 0, \; y_3 = x_3 - 1 \ge 0$.
> Уравнение: $y_1 + y_2 + y_3 = 15 - (2 + 3 + 1) = 9$.
> Способов: $\binom{9 + 3 - 1}{3 - 1} = \binom{11}{2} = 55$.

---

### Случай 4. Неравенства ($x_1 + x_2 + \dots + x_k \le n$, при $x_i \ge 0$)

* Вводим фиктивную переменную-«остаток» $x_{k+1} \ge 0$:
  $$x_1 + x_2 + \dots + x_k + x_{k+1} = n$$
* Теперь это стандартное уравнение уже для **$k + 1$ переменных**.

> [!important] Формула для неравенств:
> $$N = \binom{n + (k + 1) - 1}{(k + 1) - 1} = \binom{n + k}{k}$$

---

## ЧАСТЬ II. Метод белых и чёрных шаров (выбор без соседей)

Используется для задач типа: *«Сколькими способами из ряда в $n$ предметов можно выбрать $k$ предметов так, чтобы никакие два выбранных не стояли рядом?»*

### 1. Базовое кодирование:
* ⚫ **Чёрный шар** — предмет, который мы **выбираем** (всего $k$ штук).
* ⚪ **Белый шар** — предмет, который мы **НЕ выбираем** (всего $n - k$ штук).

---

### 2. Модель «карманов» между белыми шарами

1. Сначала выставляем в ряд все $n - k$ **белых шаров**:
   $$\text{\_ } \circ \text{ \_ } \circ \text{ \_ } \circ \text{ \_ } \dots \text{ \_ } \circ \text{ \_}$$
2. Вокруг $n - k$ белых шаров образуется ровно **$(n - k + 1)$ карманов** (позиций для вставки):
   * 1 карман слева от первого белого,
   * $(n - k - 1)$ карманов между соседними белыми,
   * 1 карман справа от последнего белого.
3. Условие **«никакие два выбранных не стоят рядом»** означает: **в каждый карман разрешено положить не более 1 чёрного шара**.
4. Нужно просто выбрать $k$ карманов из $(n - k + 1)$ доступных:

> [!important] Формула (выбор $k$ предметов из $n$ без соседних):
> $$N = \binom{n - k + 1}{k}$$
> *(если $k > n - k + 1$, то $N = 0$ — по принципу Дирихле).*

---

### 3. Метод сдвига индексов (алгебраическая биекция)

Пусть $1 \le a_1 < a_2 < \dots < a_k \le n$ — номера выбранных предметов.
Условие неналожения: $a_{i+1} - a_i \ge 2$.

Сделаем замену:
$$b_1 = a_1$$
$$b_2 = a_2 - 1$$
$$b_3 = a_3 - 2$$
$$\dots$$
$$b_k = a_k - (k - 1)$$

Тогда строгие неравенства с шагом $\ge 2$ превращаются в обычные строгие неравенства с шагом $\ge 1$:
$$1 \le b_1 < b_2 < b_3 < \dots < b_k \le n - (k - 1)$$
Выбрать $k$ строго возрастающих чисел от $1$ до $n - k + 1$ можно ровно $\binom{n - k + 1}{k}$ способами.

---

### 4. Обобщение: расстояние между выбранными не менее $d$

Если требуется, чтобы между любыми двумя выбранными предметами было как минимум $d - 1$ невыбранных (то есть $a_{i+1} - a_i \ge d$):

1. **Через склейку блоков:** каждый чёрный шар (кроме последнего) забирает с собой $d - 1$ белых шаров в единый блок:
   $$[\bullet \underbrace{\circ \dots \circ}_{d - 1}]$$
2. **Через сдвиг:** замена $b_i = a_i - (i - 1)(d - 1)$.
   Диапазон сжимается до $n - (k - 1)(d - 1)$.

> [!important] Формула (расстояние $\ge d$):
> $$N = \binom{n - (k - 1)(d - 1)}{k}$$

---

### 5. Циклический случай (предметы стоят по кругу)

Если $n$ предметов расположены **по кругу** (например, люди в хороводе, часы на циферблате) и никакие два выбранных не должны быть соседями:

> [!note] Теорема Капланского (Kaplansky's theorem):
> $$N_{\text{круг}} = \frac{n}{n - k} \binom{n - k}{k}$$

## ЧАСТЬ III. Сводная таблица всех формул

| Задача | Условие на переменные | Формула |
| :--- | :--- | :--- |
| Разбить $n$ предметов по $k$ непустым группам | $x_1 + \dots + x_k = n, \quad x_i \ge 1$ | $\dbinom{n - 1}{k - 1}$ |
| Разбить $n$ предметов по $k$ группам (могут быть пустые) | $x_1 + \dots + x_k = n, \quad x_i \ge 0$ | $\dbinom{n + k - 1}{k - 1} = \bar{C}_k^n$ |
| Произвольные минимальные размеры групп | $x_1 + \dots + x_k = n, \quad x_i \ge c_i$ | $\dbinom{n - \sum c_i + k - 1}{k - 1}$ |
| Неравенство на сумму групп | $x_1 + \dots + x_k \le n, \quad x_i \ge 0$ | $\dbinom{n + k}{k}$ |
| Выбрать $k$ из $n$ в ряду без соседей | $a_{i+1} - a_i \ge 2$ | $\dbinom{n - k + 1}{k}$ |
| Выбрать $k$ из $n$ с зазором не менее $d$ | $a_{i+1} - a_i \ge d$ | $\dbinom{n - (k - 1)(d - 1)}{k}$ |
| Выбрать $k$ из $n$ по кругу без соседей | соседи по кругу запрещены | $\dfrac{n}{n - k}\dbinom{n - k}{k}$ |
