# Задача: Коэффициенты в разложениях (Полиномиальная теорема)

> [!question] Условие
> Найти коэффициент:
> а) при $x^2 y^3 z^1$ в $(x^2 + y + z)^6$;
> б) при $x^2 y^3 z^1$ в $(x^2 y + y + z)^4$;
> в) при $x^6$ в $(1 + x + x^2 + x^3)^n$.

---

### Решение

Формула полинома:
$$(a_1 + \dots + a_m)^N = \sum_{k_1 + \dots + k_m = N} \frac{N!}{k_1! \dots k_m!} a_1^{k_1} \dots a_m^{k_m}$$

#### а) при $x^2 y^3 z^1$ в $(x^2 + y + z)^6$
Общий член: $\frac{6!}{k_1! k_2! k_3!} (x^2)^{k_1} y^{k_2} z^{k_3} = \frac{6!}{k_1! k_2! k_3!} x^{2k_1} y^{k_2} z^{k_3}$.
Приравниваем степени:
* $2k_1 = 2 \implies k_1 = 1$
* $k_2 = 3$
* $k_3 = 1$

Сумма: $k_1 + k_2 + k_3 = 1 + 3 + 1 = 5 \neq 6$.
Так как сумма степеней не равна $N=6$, такой одночлен не образуется.
**Ответ:** **$0$**.

---

#### б) при $x^2 y^3 z^1$ в $(x^2 y + y + z)^4$
Общий член: $\frac{4!}{k_1! k_2! k_3!} (x^2 y)^{k_1} y^{k_2} z^{k_3} = \frac{4!}{k_1! k_2! k_3!} x^{2k_1} y^{k_1 + k_2} z^{k_3}$.
Приравниваем степени:
* $2k_1 = 2 \implies k_1 = 1$
* $k_3 = 1$
* $k_1 + k_2 = 3 \implies 1 + k_2 = 3 \implies k_2 = 2$

Сумма: $k_1 + k_2 + k_3 = 1 + 2 + 1 = 4 = N$ (верно).
Коэффициент:
$$\frac{4!}{1! \cdot 2! \cdot 1!} = \frac{24}{2} = 12$$
**Ответ:** **$12$**.

---

#### в) при $x^6$ в $(1 + x + x^2 + x^3)^n$
Разложим основание на множители:
$$1 + x + x^2 + x^3 = (1 + x)(1 + x^2)$$
Тогда:
$$(1 + x + x^2 + x^3)^n = (1 + x)^n (1 + x^2)^n = \left(\sum_{i=0}^n \binom{n}{i} x^i\right) \left(\sum_{j=0}^n \binom{n}{j} x^{2j}\right)$$
Члены имеют вид $\binom{n}{i} \binom{n}{j} x^{i + 2j}$.
Нам нужно $i + 2j = 6 \implies i = 6 - 2j$.
Перебираем $j$:
* $j = 0 \implies i = 6$: $\binom{n}{6} \binom{n}{0} = \binom{n}{6}$
* $j = 1 \implies i = 4$: $\binom{n}{4} \binom{n}{1} = n \binom{n}{4}$
* $j = 2 \implies i = 2$: $\binom{n}{2} \binom{n}{2} = \binom{n}{2}^2$
* $j = 3 \implies i = 0$: $\binom{n}{0} \binom{n}{3} = \binom{n}{3}$

**Ответ:** 
$$\binom{n}{6} + \binom{n}{1}\binom{n}{4} + \binom{n}{2}^2 + \binom{n}{3}$$
