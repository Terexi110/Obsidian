# Задача: Наибольшее слагаемое бинома Ньютона

> [!question] Условие
> Какое слагаемое в разложении $(1 + 3)^n$ по формуле бинома Ньютона будет наибольшим?

---

### Решение

По формуле бинома Ньютона:
$$(1 + 3)^n = \sum_{k=0}^n a_k, \quad \text{где } a_k = \binom{n}{k} 3^k$$

Исследуем отношение соседних слагаемых:
$$\frac{a_{k+1}}{a_k} = \frac{\binom{n}{k+1} 3^{k+1}}{\binom{n}{k} 3^k} = \frac{\frac{n!}{(k+1)!(n - k - 1)!} \cdot 3}{\frac{n!}{k!(n - k)!}} = \frac{3(n - k)}{k + 1}$$

Слагаемые растут ($a_{k+1} \ge a_k$), пока:
$$\frac{3(n - k)}{k + 1} \ge 1 \iff 3n - 3k \ge k + 1 \iff 4k \le 3n - 1 \iff k \le \frac{3n - 1}{4}$$

* Если $\frac{3n - 1}{4}$ **не целое**: 
  Наибольшим будет слагаемое с номером:
  $$k_{\max} = \left\lfloor \frac{3n - 1}{4} \right\rfloor + 1 = \left\lfloor \frac{3n + 3}{4} \right\rfloor$$
* Если $\frac{3n - 1}{4}$ **целое** ($3n \equiv 1 \pmod 4$, например при $n = 3, 7, 11, \dots$):
  При $k = \frac{3n - 1}{4}$ отношение равно $1 \implies a_{k+1} = a_k$.
  В этом случае **два равных максимальных слагаемых**: с $k = \frac{3n - 1}{4}$ и $k = \frac{3n + 3}{4}$.

---

> [!success] Ответ
> Слагаемое с номером $k = \lfloor \frac{3n + 3}{4} \rfloor$ (при $3n \equiv 1 \pmod 4$ два наибольших слагаемых: $k = \frac{3n - 1}{4}$ и $k = \frac{3n + 3}{4}$).
