# Задача 20: Покрытие равностороннего треугольника

> [!question] Условие
> Докажите, что равносторонний треугольник нельзя покрыть двумя меньшими равносторонними треугольниками.

---

### Доказательство

Пусть $T$ — исходный равносторонний треугольник со стороной $a$. У него есть три вершины: $A, B, C$.
Расстояние между любыми двумя вершинами равно длине стороны:
$$|AB| = |BC| = |CA| = a$$

Предположим противное: пусть треугольник $T$ удалось покрыть двумя меньшими равносторонними треугольниками $T_1$ и $T_2$ со сторонами $a_1 < a$ и $a_2 < a$.

1. **Диаметр меньшего треугольника:**
   Диаметр (максимальное расстояние между любыми двумя точками) равностороннего треугольника со стороной $a_1$ равен длине его стороны $a_1$.
   Следовательно, для любых точек $P, Q \in T_1$:
   $$|PQ| \le a_1 < a$$
   Аналогично для любых точек $P, Q \in T_2$:
   $$|PQ| \le a_2 < a$$

2. **Ограничение на вершины:**
   Так как расстояние между любыми двумя вершинами исходного треугольника $T$ в точности равно $a$, ни один из меньших треугольников $T_1$ или $T_2$ не может содержать сразу две вершины треугольника $T$:
   $$\text{Каждый меньший треугольник } T_i \text{ содержит не более одной вершины } A, B, C.$$

3. **Принцип Дирихле:**
   Все 3 вершины $A, B, C$ должны быть покрыты фигурами $T_1$ и $T_2$.
   По принципу Дирихле (3 вершины в 2 множества), хотя бы один из треугольников обязан содержать не менее:
   $$\lceil 3 / 2 \rceil = 2 \text{ вершины.}$$

Получили противоречие: треугольник не может содержать более 1 вершины, но по принципу Дирихле обязан содержать не менее 2 вершин.

---

> [!success] Вывод
> Покрыть равносторонний треугольник двумя меньшими равносторонними треугольниками невозможно. Ч.Т.Д.
