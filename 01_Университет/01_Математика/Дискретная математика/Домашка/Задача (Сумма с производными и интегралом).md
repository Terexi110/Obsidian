# Задача: Сумма биномиальных коэффициентов с весами

> [!question] Условие
> Вычислить сумму:
> $$\sum_{k=0}^n C_n^k \left( k^2 + 2k - \frac{1}{k+1} \right)$$

---

### Решение

Разобьём исходную сумму на три независимые части по линейности:
$$S = \underbrace{\sum_{k=0}^n 2k C_n^k}_{(1)} + \underbrace{\sum_{k=0}^n k^2 C_n^k}_{(2)} - \underbrace{\sum_{k=0}^n \frac{C_n^k}{k+1}}_{(3)}$$

В качестве основы используем тождество бинома Ньютона:
$$(1 + x)^n = \sum_{k=0}^n C_n^k x^k$$

---

### 1. Вычисление слагаемого с $2k$ (первая производная)

Чтобы получить множитель $k$, продифференцируем тождество бинома по переменной $x$:
$$\big((1 + x)^n\big)' = \left(\sum_{k=0}^n C_n^k x^k\right)'$$
$$n(1 + x)^{n-1} = \sum_{k=0}^n k C_n^k x^{k-1}$$

Подставим $x = 1$:
$$\sum_{k=0}^n k C_n^k = n(1 + 1)^{n-1} = n \cdot 2^{n-1}$$

Умножаем на $2$, чтобы получить слагаемое с $2k$:
$$\sum_{k=0}^n 2k C_n^k = 2 \cdot n \cdot 2^{n-1} = n \cdot 2^n = 4n \cdot 2^{n-2}$$

---

### 2. Вычисление слагаемого с $k^2$ отдельно (повторное дифференцирование)

Чтобы получить второй множитель $k$ (то есть $k^2$), возьмём результат первого дифференцирования:
$$\sum_{k=0}^n k C_n^k x^{k-1} = n(1 + x)^{n-1}$$

**Шаг А.** Домножим обе части на $x$, чтобы вернуть показатель степени $x^k$:
$$\sum_{k=0}^n k C_n^k x^k = n x (1 + x)^{n-1}$$

**Шаг Б.** Продифференцируем ещё раз по $x$ (степень $k$ «спустится» во второй раз и даст $k \cdot k = k^2$):
$$\left(\sum_{k=0}^n k C_n^k x^k\right)' = \big(n x (1 + x)^{n-1}\big)'$$
$$\sum_{k=0}^n k^2 C_n^k x^{k-1} = n(1 + x)^{n-1} + n x \cdot (n - 1)(1 + x)^{n-2}$$

**Шаг В.** Подставим $x = 1$:
$$\sum_{k=0}^n k^2 C_n^k = n \cdot 2^{n-1} + n(n - 1) \cdot 2^{n-2}$$

Вынесем общий множитель $n \cdot 2^{n-2}$ (учитывая, что $2^{n-1} = 2 \cdot 2^{n-2}$):
$$\sum_{k=0}^n k^2 C_n^k = n \cdot 2^{n-2} \big(2 + (n - 1)\big) = n(n + 1) \cdot 2^{n-2}$$

> [!tip] Альтернативный взгляд на $k^2$ через факториальные степени
> Можно представить $k^2 = k(k - 1) + k$.
> Тогда вторая производная $f''(1) = n(n - 1)2^{n-2}$ даёт $\sum k(k - 1) C_n^k$, а первая производная $f'(1) = n 2^{n-1}$ даёт $\sum k C_n^k$. 
> Их сумма в точности равна: $n(n - 1)2^{n-2} + n 2^{n-1} = n(n + 1)2^{n-2}$.

---

### 3. Вычисление дробного слагаемого $\frac{1}{k+1}$ (первообразная / интеграл)

Интегрирование степени даёт деление на показатель: $\int x^k \, dx = \frac{x^{k+1}}{k+1}$.
Проинтегрируем обе части бинома Ньютона от $0$ до $1$:
$$\int_0^1 (1 + x)^n \, dx = \sum_{k=0}^n C_n^k \int_0^1 x^k \, dx$$
$$\left. \frac{(1 + x)^{n+1}}{n + 1} \right|_0^1 = \sum_{k=0}^n \frac{C_n^k}{k + 1} \left. x^{k+1} \right|_0^1$$
$$\frac{2^{n+1} - 1}{n + 1} = \sum_{k=0}^n \frac{C_n^k}{k + 1}$$

---

### 4. Собираем все три слагаемых вместе

Подставим найденные значения в исходное разбиение:
$$S = \underbrace{4n \cdot 2^{n-2}}_{\text{слагаемое с } 2k} + \underbrace{n(n + 1) 2^{n-2}}_{\text{слагаемое с } k^2} - \underbrace{\frac{2^{n+1} - 1}{n + 1}}_{\text{дробное слагаемое}}$$

Складываем слагаемые со степенью $2^{n-2}$:
$$4n \cdot 2^{n-2} + n(n + 1) 2^{n-2} = n \cdot 2^{n-2} \big(4 + (n + 1)\big) = n(n + 5) 2^{n-2}$$

Итоговый результат:
$$S = n(n + 5) 2^{n-2} - \frac{2^{n+1} - 1}{n + 1}$$

---

> [!success] Ответ
> $$n(n + 5) 2^{n-2} - \frac{2^{n+1} - 1}{n + 1}$$
