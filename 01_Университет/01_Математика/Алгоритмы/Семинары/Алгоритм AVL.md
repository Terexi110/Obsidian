# Алгоритм построения и балансировки AVL-дерева

Связанные конспекты: [[Дерево поиска и AVL]], [[Деревья поиска и AVL]]

---

## 1. Базовые определения

**AVL-дерево (АВЛ-дерево)** — это сбалансированное двоичное дерево поиска (BST), обладающее следующим свойством сбалансированности:

> Для **любого** узла $v$ разность высот его левого ($v_L$) и правого ($v_R$) поддеревьев не превышает по модулю 1:
> $$|h(v_L) - h(v_R)| \le 1$$
> где $h(v)$ — глубина (высота) поддерева с корнем в узле $v$. Высота пустого поддерева принимается равной $0$ (или $-1$, если лист имеет высоту $0$).

### Фактор баланса (Balance Factor, BF)
Для каждого узла $v$ определяется фактор баланса:
$$\text{BF}(v) = h(v_R) - h(v_L)$$

* $\text{BF}(v) = 0$ — поддеревья равны по высоте;
* $\text{BF}(v) = 1$ — правое поддерево выше левого на 1;
* $\text{BF}(v) = -1$ — левое поддерево выше правого на 1;
* $|\text{BF}(v)| > 1$ — **дерево разбалансировано**, требуется поворот:
  * $\text{BF}(v) = +2$ — перевес вправо;
  * $\text{BF}(v) = -2$ — перевес влево.

## 2. Общий алгоритм вставки элемента (построения дерева)

Построение AVL-дерева из последовательности ключей сводится к поочередной вставке каждого элемента:

1. **Обычная вставка BST:**
   * Спускаемся от корня: если новый ключ меньше текущего узла — идем влево, если больше — вправо.
   * Добавляем элемент как новый лист дерева (высота $h = 1$).

2. **Обратный ход (подъем по стеку рекурсии к корню):**
   * Для каждого предка пересчитываем высоту:
     $$h(v) = 1 + \max(h(v_L), h(v_R))$$
   * Вычисляем фактор баланса $\text{BF}(v) = h(v_R) - h(v_L)$.

3. **Балансировка (если обнаружен дисбаланс $|\text{BF}(v)| = 2$):**
   * Применяем один из **4 поворотов** (см. ниже).
   * После поворота высота поддерева восстанавливается до исходного значения до вставки, поэтому выше по дереву дисбаланс больше не возникает (для вставки достаточно не более одного поворота).

---

## 3. Случаи дисбаланса и 4 типа поворотов

Пусть в узле $a$ зафиксирован дисбаланс $|\text{BF}(a)| = 2$.

### 3.1. Малый левый поворот (RR-случай)
Возникает, когда перевес идет **вправо-вправо**: узел $a$ имеет $\text{BF}(a) = +2$, а его правый сын $b$ имеет $\text{BF}(b) \ge 0$.

```text
       a                             b
      / \                           / \
     A   b         ----->          a   C
        / \                       / \
       B   C                     A   B
```

* **Высоты до поворота:**
  * Поддерево $A$: высота $H-3$
  * Правый сын $b$: высота $H-1$ (поддеревья $B$ и $C$ имеют высоту $H-2$)
  * Баланс узла $a$: $h(b) - h(A) = (H-1) - (H-3) = 2$
* **После поворота:**
  * $b$ становится новым корнем.
  * $a$ становится левым потомком $b$.
  * Поддерево $B$ становится правым потомком $a$.
  * Разница высот сбалансирована: $|(H-1) - (H-2)| \le 1$.

---

### 3.2. Малый правый поворот (LL-случай)
Симметричен малому левому: перевес **влево-влево** ($\text{BF}(a) = -2$, у левого сына $b$ $\text{BF}(b) \le 0$).

```text
         a                         b
        / \                       / \
       b   C       ----->        A   a
      / \                           / \
     A   B                         B   C
```

* **Суть:**
  * $b$ становится новым корнем.
  * $a$ становится правым потомком $b$.
  * Поддерево $B$ становится левым потомком $a$.

---

### 3.3. Большой левый поворот (RL-случай)
Возникает при зигзагообразном перевесе **вправо-влево**: узел $a$ имеет $\text{BF}(a) = +2$, но его правый сын $b$ имеет перевес влево ($\text{BF}(b) < 0$).

Один малый поворот здесь не поможет — требуется два последовательных малых поворота:
1. **Малый правый поворот** вокруг правого сына $b$ (выпрямляет зигзаг $a \to b \to c$ в прямую цепочку $a \to c \to b$).
2. **Малый левый поворот** вокруг узла $a$ ($c$ поднимается в корень).

```text
      a                     a
     / \                   / \                      c
    P   b      (1)        P   c        (2)        /   \
       / \    ----->         / \     ----->      a     b
      c   S                 Q   b               / \   / \
     / \                       / \             P   Q R   S
    Q   R                     R   S
```

* **Высоты до поворота:**
  * Поддерево $P$: $H-3$
  * Правый сын $b$: содержит поддерево $c$ высоты $H-2$ (с поддеревьями $Q$ высоты $H-3$ и $R$ высоты $H-4$) и поддерево $S$ высоты $H-2$.
* **После двух шагов:**
  * $c$ — корень с высотой $H-1$.
  * $a$ — левый сын с поддеревьями $P$ ($H-3$) и $Q$ ($H-3$).
  * $b$ — правый сын с поддеревьями $R$ ($H-4$) и $S$ ($H-2$).
  * Баланс полностью восстановлен.

---

### 3.4. Большой правый поворот (LR-случай)
Симметричен большому левому: перевес **влево-вправо** ($\text{BF}(a) = -2$, а у левого сына $b$ $\text{BF}(b) > 0$).

1. **Малый левый поворот** вокруг левого сына $b$.
2. **Малый правый поворот** вокруг узла $a$.

---

## 4. Сводная таблица выбора поворота

Пусть узел $A$ несбалансирован ($|\text{BF}(A)| = 2$):

| $\text{BF}(A)$ | Потомок с перевесом | $\text{BF}$ потомка | Конфигурация | Необходимый поворот |
| :---: | :---: | :---: | :---: | :--- |
| **$-2$** (влево) | Левый сын $L$ | $\le 0$ | $LL$ | **Малый правый** вокруг $A$ |
| **$-2$** (влево) | Левый сын $L$ | $> 0$ | $LR$ | **Большой правый** (малый левый вокруг $L$ + малый правый вокруг $A$) |
| **$+2$** (вправо) | Правый сын $R$ | $\ge 0$ | $RR$ | **Малый левый** вокруг $A$ |
| **$+2$** (вправо) | Правый сын $R$ | $< 0$ | $RL$ | **Большой левый** (малый правый вокруг $R$ + малый левый вокруг $A$) |

---

## 5. Вычислительная сложность

* **Высота дерева:** не более $1.44 \log_2(n + 2) = O(\log n)$.
* **Поиск:** $O(\log n)$.
* **Вставка:** $O(\log n)$ (спуск к листу $O(\log n)$ + пересчет высот и не более 1 поворота $O(1)$).
* **Удаление:** $O(\log n)$ (при удалении может потребоваться до $O(\log n)$ поворотов на пути к корню).
